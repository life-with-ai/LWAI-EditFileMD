# EditFileMD 1.5.0

Выпуск добавляет работу с исходным текстом и конфигурационными файлами.

## Файлы выпуска

- `EditFileMD-1.5.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.5.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

SHA-256 portable ZIP:

`057880337838E666A1DE1462E84E470B99489971C4F780723DCBAE64981FD316`

## Изменения

- Добавлено открытие, редактирование и чтение исходного текста HTML, CSS, JavaScript, TypeScript, JSON, XML, YAML, SVG и Python.
- Поддержаны распространённые конфигурационные расширения и точные имена файлов, включая `.gitignore`, `.editorconfig`, `.env`, `Dockerfile` и `Pipfile`.
- Поддерживаемые исходные форматы получили языковую подсветку.
- Дерево и вкладки используют отдельные иконки категорий файлов.
- Исходные и конфигурационные файлы открываются как текст без исполнения содержимого и без визуального web-preview.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Проверенные системы: Windows 8.1 x64, Windows 10 x64 и Windows Server 2025 Standard 24H2 x64. Совместимость с Windows 11 x64 не проверена.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Известные ограничения

- EXE не подписан коммерческим сертификатом; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
