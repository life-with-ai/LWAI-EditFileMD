# EditFileMD 1.11.0

Выпуск улучшает отображение Markdown-документов, адаптацию интерфейса к экрану и сохранение состояния документов при переключении.

## Файлы выпуска

- `EditFileMD-1.11.0-windows-x64-portable.zip` – portable-версия приложения;
- `EditFileMD-1.11.0-windows-x64-portable.zip.sha256` – контрольная сумма SHA-256.

SHA-256 portable ZIP:

`1AE56F9B79B1DFA204328442873AF5B830F90C749D2CEE312DDFBB74E4B9D27C`

## Изменения

- Адаптивный экранный профиль автоматически подбирает масштаб интерфейса и размеры текста для текущего монитора; ручной режим сохраняет выбранные пользователем значения.
- Насыщенность заголовков Markdown настраивается независимо для редактора и области чтения.
- Режим одной вкладки запоминает позиции недавно открытых документов, а открытые вкладки сохраняют выделение, историю отмены и повтора и готовое оформление редактора.
- Нетабличное Markdown-содержимое переносится внутри области чтения, а широкие таблицы сохраняют собственную горизонтальную прокрутку.
- Блоки исходного кода получили компактную панель с названием языка и кнопкой копирования, настройку размера текста и масштабируемый межстрочный интервал.
- Обновлено оформление встроенного кода, клавиш, списков задач, цитат, сносок и горизонтальных полос прокрутки Markdown.
- Для обычного текста чтения по умолчанию используется Verdana с системными и встроенными резервными шрифтами.
- Увеличены диалоги преобразования, уменьшена минимальная ширина дерева проектов и улучшено выравнивание окна горячих клавиш.
- Исправлены перекрытие текста кнопкой копирования, повторная загрузка недоступного локального изображения, пустая область при возврате к документу и повторное применение оформления при переключении вкладок.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Проверенные системы: Windows 8.1 x64, Windows 10 x64 и Windows Server 2025 Standard 24H2 x64. Совместимость с Windows 11 x64 не проверена.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
