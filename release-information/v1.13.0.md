# LWAI-EditFileMD 1.13.0

Выпуск добавляет настраиваемый экспорт PDF с предпросмотром и выбором страниц.

## Файлы выпуска

- `LWAI-EditFileMD-1.13.0-windows-x64-portable.zip` – portable-версия приложения;
- `LWAI-EditFileMD-1.13.0-windows-x64-portable.zip.sha256` – контрольная сумма SHA-256.

## Изменения

### Добавлено

- Вкладка «Экспорт PDF» с сохраняемыми параметрами листа, полей, масштаба, переносов, оформления, заливок, колонтитулов и метаданных.
- Предпросмотр готовых PDF-страниц с прокруткой, навигацией и увеличением просмотра; его можно отключить для прямого экспорта.
- Сохранение всех страниц или выбранного диапазона из предпросмотра.

### Изменено

- Числовые поля настроек поддерживают ввод и постоянные стрелки; отдельные значения восстанавливаются текстовой ссылкой «Сбросить».
- Руководство пользователя дополнено отдельным разделом экспорта PDF и уточнёнными инструкциями по основным сценариям.

### Исправлено

- Таблицы при экспорте PDF используют доступную ширину страницы и могут продолжаться на следующих листах без отдельной титульной страницы.

## Совместимость конфигурации

Настройки и рабочее состояние версии 1.12.0 совместимы с 1.13.0. Закройте обе версии, распакуйте новый архив в отдельную папку, скопируйте в неё папку `data` из 1.12.0 и запустите `LWAI-EditFileMD.exe`. Пользовательские документы остаются в исходных папках.

## Системные требования

- Windows x64 и Microsoft Edge WebView2 Runtime;
- Windows 8.1 x64 – проверено;
- Windows 10 x64 – проверено;
- Windows Server 2025 Standard 24H2 x64 – проверено;
- Windows 11 x64 – поддержка предусмотрена; практическое тестирование не выполнялось.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск

1. Проверить SHA-256 архива по сопутствующему файлу.
2. Полностью распаковать архив в пользовательскую папку с правом записи.
3. Запустить `LWAI-EditFileMD.exe`.

## Известные ограничения

- EXE не подписан цифровым сертификатом; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в ZIP.
- Размещение содержимого на одной странице не подбирается автоматически: при необходимости уменьшите масштаб PDF или измените формат листа.

## Локальная работа и поддержка

Документы и настройки хранятся локально. Предпросмотр PDF и выбор страниц работают без сетевой загрузки библиотек.
