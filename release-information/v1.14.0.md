# LWAI-EditFileMD 1.14.0

Создание файлов и папок внутри проектов.

## Файлы выпуска

- `LWAI-EditFileMD-1.14.0-windows-x64-portable.zip` – portable-версия приложения;
- `LWAI-EditFileMD-1.14.0-windows-x64-portable.zip.sha256` – контрольная сумма SHA-256.

## Изменения

### Добавлено

- Создание пустых файлов поддерживаемых текстовых форматов и папок через меню «Файл» и меню корня проекта.
- Выбор проекта, родительской папки и формата; расширение добавляется автоматически, специальные имена выбираются готовыми вариантами.
- Проверка имени и совпадения с существующим объектом; существующие файлы и папки не перезаписываются.

### Изменено

- Руководство дополнено разделом «Создание файлов и папок»; «Настройки приложения» расположены после «Начала работы».
- Команды подключения проекта и открытия файла получили отдельные значки, отличающиеся от значков создания.

### Исправлено

- Убрана квадратная рамка названия вкладки документа после клика мышью и ввода с клавиатуры.

## Совместимость конфигурации

Настройки и рабочее состояние версии 1.13.0 совместимы с 1.14.0. Закройте обе версии, распакуйте новый архив в отдельную папку, скопируйте в неё папку `data` из 1.13.0 и запустите `LWAI-EditFileMD.exe`. Пользовательские документы остаются в исходных папках.

## Системные требования

- Windows 8.1 x64, Windows 10 x64 или Windows Server 2025 Standard 24H2 x64;
- Windows 11 x64 – поддержка предусмотрена; практическое тестирование не выполнялось;
- Microsoft Edge WebView2 Runtime.

WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск

1. Проверить SHA-256 архива по сопутствующему файлу.
2. Полностью распаковать архив в пользовательскую папку с правом записи.
3. Запустить `LWAI-EditFileMD.exe`.

## Ограничения

- EXE не подписан цифровым сертификатом; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в ZIP.
- Создание доступно внутри уже добавленного проекта; для записи нужны права на выбранную папку.
