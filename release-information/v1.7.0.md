# EditFileMD 1.7.0

Выпуск расширяет настройки, оформление Markdown и устойчивость дерева проектов.

## Файлы выпуска

- `EditFileMD-1.7.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.7.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

SHA-256 portable ZIP:

`CCBCCA7BFCEAC6744445DE8C0F2EEDBCDF32BD4BC22D837C592010C8497E1927`

## Изменения

- Добавлены сброс настроек с подтверждением и выбор начального режима новых документов.
- Дерево проектов обрабатывает внешние переименования и отдельно обозначает недоступные корневые проекты.
- Настройки цветов и заливки иконок дерева разделены по типам элементов.
- Добавлены варианты оформления Markdown-заголовков и выделенного текста.
- Markdown-таблицы автоматически распределяют ширину колонок.
- Синхронизация прокрутки разделённого режима учитывает размеры областей и сводит начало и конец документа.
- В приложение встроены Inter и Cascadia Code с применимыми лицензиями.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
