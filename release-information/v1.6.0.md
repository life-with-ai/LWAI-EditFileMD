# EditFileMD 1.6.0

Выпуск расширяет оформление чтения, редактирования и дерева проектов.

## Файлы выпуска

- `EditFileMD-1.6.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.6.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

SHA-256 portable ZIP:

`F438EE8808173114DB7C043DBDCD60C19C228B231488FAA65F7CA16981677CDC`

## Изменения

- Добавлены независимые размеры, системные шрифты и отступы текста и кода для редактирования и чтения.
- Оформление номеров строк и активной строки редактора получило отдельные цветовые параметры.
- Добавлены варианты толщины полос прокрутки и оформления Markdown-таблиц, встроенного кода и цитат.
- Корневые проекты можно перемещать с сохранением выбранного порядка.
- Документы со смешанными LF/CRLF доступны для редактирования и нормализуются при обычном сохранении.
- Разделитель разделённого режима не увеличивает ширину рабочей области.
- Скорректировано оформление папок и системных значков приложения.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Проверенные системы: Windows 8.1 x64, Windows 10 x64 и Windows Server 2025 Standard 24H2 x64. Совместимость с Windows 11 x64 не проверена.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
