# LWAI-EditFileMD 1.16.0

Стартовый экран, просмотр локальных PDF и поддержка дополнительных форматов исходного кода.

## Файлы выпуска

- `LWAI-EditFileMD-1.16.0-windows-x64-portable.zip` – portable-версия приложения.
- `LWAI-EditFileMD-1.16.0-windows-x64-portable.zip.sha256` – контрольная сумма SHA-256.

## Изменения

### Добавлено

- На экране «Выберите действие» можно добавить существующий проект, создать новый проект или открыть отдельный файл.
- Локальные PDF открываются во вкладках для просмотра с прокруткой, переходом по номеру страницы, масштабированием и подгонкой по ширине.
- Добавлена поддержка текстовых файлов PID и исходного кода BSL, C, C++, C#, Java, Kotlin, Go, Dart, Swift, Ruby, Lua, Perl, R, Pascal, PHP, Groovy, Julia, Haskell, Clojure, Erlang и Fortran.
- Поддерживаются CMake, Protocol Buffers, Gherkin, Diff, Sass, SCSS, Pug и Jinja2, включая распознавание CMakeLists.txt по имени.

### Изменено

- Добавлена подсветка синтаксиса для Rust, SQL, PowerShell, Shell, TOML, INI, .properties и Dockerfile.
- В просмотре изображений можно ввести масштаб числом.

### Исправлено

- В совместном режиме прокрутка исходного кода синхронизируется в обе стороны.

## Совместимость конфигурации

Перенос настроек и рабочего состояния из версии 1.15.0 в 1.16.0 проверен на Windows 8.1 x64 и Windows 10 x64. Закройте обе версии, распакуйте новый архив в отдельную папку и скопируйте в неё папку `data` из 1.15.0.

## Системные требования

- Windows 8.1 x64 и Windows 10 x64 – проверено.
- Windows 11 x64 и Windows Server 2025 Standard 24H2 x64 – поддержка предусмотрена; практическое тестирование этой версии не выполнялось.
- Microsoft Edge WebView2 Runtime.

WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск

1. Проверьте SHA-256 архива по сопутствующему файлу.
2. Полностью распакуйте архив в пользовательскую папку с правом записи.
3. Запустите `LWAI-EditFileMD.exe`.

## Ограничения

- PDF-файлы открываются только для просмотра.
- EXE без цифровой подписи. Windows SmartScreen может показать предупреждение о неизвестном издателе.
- WebView2 Runtime устанавливается отдельно.
