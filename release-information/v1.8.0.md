# EditFileMD 1.8.0

Выпуск добавляет управление кодировками и окончаниями строк.

## Файлы выпуска

- `EditFileMD-1.8.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.8.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

SHA-256 portable ZIP:

`DF69AAE59509A09D32531782E541E72072B36423362BFF30BD7AAAA58D80CB3D`

## Изменения

- Добавлены чтение и запись UTF-8, UTF-8 с BOM, UTF-16 LE, UTF-16 BE, Windows-1251, Windows-1252, CP866, KOI8-R, KOI8-U и ISO-8859-5.
- Добавлены автоматическое определение и ручное повторное открытие документа в выбранной кодировке.
- Активный документ можно преобразовать в выбранную кодировку, LF или CRLF.
- Открытие документа сохраняет исходные байты; непредставимые символы блокируют запись до изменения файла.
- Добавлены настройки кодировок и окончаний строк с индикаторами фактического формата.
- Недоступный сетевой ресурс не блокирует интерфейс и локальные проекты; работа восстанавливается после возвращения пути.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
