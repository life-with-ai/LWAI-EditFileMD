# EditFileMD 1.10.0

Выпуск расширяет работу с Markdown-документами, добавляет панель форматирования и сохраняет индивидуальное состояние проектов и вкладок.

## Файлы выпуска

- `EditFileMD-1.10.0-windows-x64-portable.zip` – portable-версия приложения;
- `EditFileMD-1.10.0-windows-x64-portable.zip.sha256` – контрольная сумма SHA-256.

SHA-256 portable ZIP:

`933F2B01AA6350A2D5C2C479E82BA63C303E0BA3C02E9FE912FB846965EDCDCD`

## Изменения

- Начальный YAML front matter отображается отдельным компактным блоком и не включается в PDF.
- Поддержаны сноски, раскрываемые блоки, клавиши, нижние и верхние индексы и дополнительные атрибуты ссылок и изображений.
- Добавлена перемещаемая панель форматирования с отменой и повтором действий, жирным, курсивным и зачёркнутым текстом и изменением размера текста.
- Состояние свёрнутых корневых проектов сохраняется и восстанавливается между запусками.
- Каждая вкладка сохраняет собственные позиции прокрутки редактора и области просмотра при переключении между документами.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Проверенные системы: Windows 8.1 x64, Windows 10 x64 и Windows Server 2025 Standard 24H2 x64. Совместимость с Windows 11 x64 не проверена.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
