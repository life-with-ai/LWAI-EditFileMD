# LWAI-EditFileMD 1.12.0

Выпуск добавляет встроенную пользовательскую помощь, расширяет поддержку текстовых форматов и обновляет публичное имя и визуальное оформление приложения.

## Файлы выпуска

- `LWAI-EditFileMD-1.12.0-windows-x64-portable.zip` – portable-версия приложения;
- `LWAI-EditFileMD-1.12.0-windows-x64-portable.zip.sha256` – контрольная сумма SHA-256.

SHA-256 portable ZIP:

`77FEAAF31812262BC2D4FC0494FC92E105B9F7E28EAF0BB38F31B0213612BCB6`

## Изменения

- Добавлены полноценное встроенное руководство пользователя и отдельная Markdown-справка на русском и английском языках.
- Добавлена редактируемая поддержка `.ps1`, `.psm1`, `.psd1`, `.cmd`, `.bat`, `.sh`, текстовых `.pub` и `.ppk` без исполнения содержимого.
- Бинарные Microsoft Publisher `.pub` контролируемо отклоняются без изменения файла.
- Скрытые и системные элементы дерева проектов получили независимые настройки отображения; обычные имена с начальной точкой больше не считаются скрытыми без атрибута Hidden.
- Публичное название изменено на `LWAI-EditFileMD`, обновлены логотипы и иконки приложения.
- Новые рабочие области открываются в разделённом режиме с пропорцией 45% для редактора и 55% для просмотра; начальная ширина дерева адаптируется к экрану.
- Индикаторы кодировки и типа переноса строк включены по умолчанию для новых конфигураций.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Проверенные системы: Windows 8.1 x64, Windows 10 x64 и Windows Server 2025 Standard 24H2 x64. Совместимость с Windows 11 x64 не проверена.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в пользовательскую папку с правом записи.
4. Запустить `LWAI-EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.
- При живом изменении размера окна область WebView может кратковременно отставать от нативного окна.

## Локальность данных

LWAI-EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
