# LWAI-EditFileMD 1.15.0

Сохранение правок при смене режима, создание новых проектов и поддержка дополнительных текстовых форматов.

## Файлы выпуска

- `LWAI-EditFileMD-1.15.0-windows-x64-portable.zip` – portable-версия приложения.
- `LWAI-EditFileMD-1.15.0-windows-x64-portable.zip.sha256` – контрольная сумма SHA-256.

## Изменения

### Добавлено

- В окне «Создать новый проект» можно выбрать расположение и проверить имя папки перед созданием. После подтверждения новая папка появляется в дереве проектов.
- Файлы `.log`, `.rs`, `.sql`, `.csv` и `.tsv` можно открывать, создавать и редактировать.
- В строке вкладок появилась кнопка возврата автоматически скрытой верхней панели.

### Изменено

- Режимы документа называются «Просмотр», «Редактирование» и «Совместный».
- Отмена, повтор, сохранение и отказ от несохранённых правок доступны с верхней панели во всех трёх режимах текстового документа.
- Названия команд меню «Файл» различают добавление готового проекта, создание нового проекта и создание файлов и папок внутри проекта.

### Исправлено

- Несохранённые правки больше не исчезают при переключении режима документа.

## Совместимость конфигурации

Настройки и рабочее состояние версии 1.14.0 совместимы с 1.15.0. Закройте обе версии, распакуйте новый архив в отдельную папку, скопируйте в неё папку `data` из 1.14.0 и запустите `LWAI-EditFileMD.exe`. Пользовательские документы остаются в исходных папках.

## Системные требования

- Windows 8.1 x64, Windows 10 x64 или Windows Server 2025 Standard 24H2 x64.
- Windows 11 x64 – поддержка предусмотрена; практическое тестирование не выполнялось.
- Microsoft Edge WebView2 Runtime.

WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск

1. Проверьте SHA-256 архива по сопутствующему файлу.
2. Полностью распакуйте архив в пользовательскую папку с правом записи.
3. Запустите `LWAI-EditFileMD.exe`.

## Ограничения

- EXE без цифровой подписи. Windows SmartScreen может показать предупреждение о неизвестном издателе.
- WebView2 Runtime устанавливается отдельно.
- Для создания и сохранения файлов и папок требуются права на запись в выбранном расположении.
