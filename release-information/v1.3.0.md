# EditFileMD 1.3.0

Выпуск расширяет настройки интерфейса, редактирования и чтения Markdown.

## Файлы выпуска

- `EditFileMD-1.3.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.3.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

SHA-256 portable ZIP:

`C4C7106B5F429FC63FF024E8EF546DFC3DC99DC789BD35C3B8C21B9957D688FA`

## Изменения

- Настройки разделены на вкладки `Основные`, `Интерфейс`, `Редактирование` и `Чтение`.
- Для редактора и чтения доступны независимые шрифты, межстрочные интервалы, цвета фона и текста.
- Markdown поддерживает общую и поэлементную цветовую палитру.
- Верхняя панель, проекты, вкладки и дерево получили независимые цветовые настройки.
- При запуске можно восстановить предыдущую сессию или открыть пустую область проектов.
- Устранено циклическое восстановление устаревших вкладок после повреждённого состояния сессии.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Проверенные системы: Windows 8.1 x64, Windows 10 x64 и Windows Server 2025 Standard 24H2 x64. Совместимость с Windows 11 x64 не проверена.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
