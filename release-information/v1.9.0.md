# EditFileMD 1.9.0

Выпуск добавляет экспорт в PDF, единую панель поиска и стандартное меню приложения.

## Файлы выпуска

- `EditFileMD-1.9.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.9.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

SHA-256 portable ZIP:

`DE690768DC58CC1171F895B93CDEB642FE9FB291347EBB2A6316773AC04ED948`

## Изменения

- Добавлен экспорт активного поддерживаемого текстового документа в PDF через системное окно сохранения Windows.
- Markdown экспортируется в оформленном виде, а другие поддерживаемые форматы — как текст без исполнения содержимого.
- Экспорт использует текущий текст редактора, включая несохранённые изменения, и не изменяет исходный файл.
- Команды распределены между меню `Файл`, `Правка`, `Вид` и `Справка`.
- Добавлена единая панель поиска для чтения и редактирования с заменой в редактируемом тексте.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Проверенные системы: Windows 8.1 x64, Windows 10 x64 и Windows Server 2025 Standard 24H2 x64. Совместимость с Windows 11 x64 не проверена.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
