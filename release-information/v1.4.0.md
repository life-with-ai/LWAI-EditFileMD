# EditFileMD 1.4.0

Выпуск расширяет дерево проектов, просмотр изображений, работу вкладок и перечитывание документов.

## Файлы выпуска

- `EditFileMD-1.4.0-windows-x64-portable.zip` — portable-версия приложения;
- `EditFileMD-1.4.0-windows-x64-portable.zip.sha256` — контрольная сумма SHA-256.

SHA-256 portable ZIP:

`889D226E62843AB76CA77F78A8CA45010C0549842E277050BBA29DDF3A798A60`

## Изменения

- Дерево показывает обычные файлы любых расширений и файлы без расширения.
- Добавлена сохраняемая настройка показа скрытых файлов и папок.
- Неподдерживаемые файлы выбираются без чтения содержимого, создания вкладки и внешнего запуска.
- PNG, JPEG, GIF, WebP и BMP открываются в режиме чтения с масштабированием и прокруткой.
- Переполненная панель вкладок получила навигацию и команды закрытия всех либо незакреплённых вкладок.
- Добавлены руководство пользователя, компактный режим дерева и автоматическое перечитывание внешних изменений.
- Устранено пустое состояние редактора после переключения документов и смещение дерева при сужении панели.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Проверенные системы: Windows 8.1 x64, Windows 10 x64 и Windows Server 2025 Standard 24H2 x64. Совместимость с Windows 11 x64 не проверена.

Microsoft Edge WebView2 Runtime доступен на [официальной странице Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Запуск

1. Скачать portable ZIP и файл контрольной суммы.
2. Проверить SHA-256 архива.
3. Распаковать архив в пользовательскую папку с правом записи.
4. Запустить `EditFileMD.exe`.

## Известные ограничения

- EXE не подписан коммерческим сертификатом; Windows SmartScreen может показать предупреждение неизвестного издателя.
- Microsoft Edge WebView2 Runtime не включён в portable ZIP.
- Совместимость с Windows 11 x64 не проверена.

## Локальность данных

EditFileMD работает локально и не использует аккаунт, телеметрию или облачную синхронизацию.
