# EditFileMD

`EditFileMD` — бесплатный локальный portable-редактор Markdown, обычного текста и поддерживаемых исходных файлов для Windows. В одном окне доступны дерево папок, вкладки, оформленное чтение и редактирование.

## Скачать

Последняя опубликованная версия — `1.9.0`: [GitHub Releases](https://github.com/life-with-ai/EditFileMD/releases/latest).

Скачайте файл `EditFileMD-1.9.0-windows-x64-portable.zip`. Файл с расширением `.sha256` позволяет проверить целостность архива.

## Основные возможности

- Markdown, TXT, распространённые исходные и конфигурационные файлы открываются как текст без исполнения содержимого.
- Несколько папок, дерево файлов, обычные и закреплённые вкладки помогают вести рабочую область в одном окне.
- Доступны чтение, редактирование, разделённый просмотр, поиск, замена и экспорт поддерживаемых текстовых документов в PDF.
- Markdown поддерживает GFM-таблицы, task lists, локальные изображения и подсветку кода; PNG, JPEG, GIF, WebP и BMP открываются в отдельном режиме чтения.
- Приложение определяет поддерживаемые кодировки и преобразует документы между UTF-8, UTF-16, распространёнными legacy-кодировками, LF и CRLF с проверкой символов до записи.
- Автосохранение, контроль внешних изменений и перечитывание документов защищают текущую работу от случайной потери.
- Светлая и тёмная темы, русский и английский интерфейс, шрифты, размеры, отступы и оформление Markdown настраиваются независимо.
- Открытые документы, проекты, вкладки и параметры рабочей области восстанавливаются между запусками.

## Системные требования

- Windows x64;
- Microsoft Edge WebView2 Runtime.

Проверенные системы: Windows 8.1 x64, Windows 10 x64 и Windows Server 2025 Standard 24H2 x64. Совместимость с Windows 11 x64 не проверена.

Если Microsoft Edge WebView2 Runtime отсутствует, загрузите его с [официальной страницы Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Portable-запуск

1. Скачать ZIP и при необходимости проверить SHA-256.
2. Полностью распаковать архив в пользовательскую папку с правом записи.
3. Запустить `EditFileMD.exe`.

Установка не требуется. Настройки и состояние рабочей области хранятся в каталоге `data` рядом с приложением, а документы остаются в выбранных пользователем папках.

## Безопасность и приватность

Приложение работает локально без аккаунта, телеметрии, сервера и облачной синхронизации. Активный HTML в Markdown фильтруется, удалённые ресурсы не загружаются, неподдерживаемые файлы не запускаются.

EXE не подписан коммерческим сертификатом; при первом запуске Windows SmartScreen может показать предупреждение неизвестного издателя.
