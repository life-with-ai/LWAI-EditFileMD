# Поддержка EditFileMD

## Сообщения об ошибках

Сообщения об ошибках и предложения функций принимаются через [GitHub Issues](https://github.com/life-with-ai/LWAI-EditFileMD/issues).

В сообщении об ошибке необходимо указать:

1. версию `EditFileMD`;
2. версию и архитектуру Windows;
3. последовательность действий для воспроизведения;
4. ожидаемый результат;
5. фактический результат;
6. текст сообщения об ошибке, если оно отображается.

Для примеров следует использовать только синтетические файлы и данные. Не допускается публиковать реальные рабочие документы, персональные данные, приватные каталоги, токены, ключи и иные конфиденциальные сведения.

## Предложения функций

Предложение должно описывать пользовательскую задачу, ожидаемый результат и предполагаемый сценарий использования. Публикация предложения не означает обязательство реализовать его или включить в определённую версию.

## Уязвимости

Сведения об уязвимостях не следует размещать в публичных Issues. Для таких сообщений используется порядок, установленный в [SECURITY.md](SECURITY.md).

## Границы поддержки

Исходный код приложения не публикуется. Pull requests с изменениями программного кода не принимаются. Условия использования приложения определены в файле [LICENSE](LICENSE).
